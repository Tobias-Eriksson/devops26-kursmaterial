# Kontocheck — M1, steg 0

**Från commit till produktion** — det här är steg 0 i dagens M1-lab
(`labs/m1-forsta-commit.md`), session 1. Ingen förberedelse hemma behövs:
vi skapar kontona tillsammans nu, på plats.

## 1. GitHub

- [ ] Skapa ett GitHub-konto om du inte redan har ett: https://github.com/join
- **Valfritt tips:** ansök gärna om **GitHub Education** (fler gratis
      Actions-minuter m.m.): https://education.github.com/discount_requests/application
      — godkänns oftast inom ett par dagar, så väntan blockerar inget. **Inte
      nödvändigt:** publika repon har redan fria Actions-minuter, och
      Codespaces gratisnivå (120 core-timmar/månad) räcker gott för kursen.

## 2. CSC (molnet vi använder)

- [ ] Skapa ett CSC-konto via **Haka** (din Arcada-inloggning):
      https://sui.csc.fi — logga in via Haka, välj Arcada som hemorganisation.
- [ ] Logga in på **MyCSC** (https://my.csc.fi) med samma Haka-inloggning.

Kontot räcker idag. **Ert eget CSC-projekt** — det som ger tillgång till
molnet — skapar ni efter labben, se avsnitt 3.

**CSC strular?** Inte blockerande idag — molnet behövs på riktigt först i
session 7. Säg till läraren så det inte glöms bort, och fortsätt.

## 3. Före session 7: ert eget CSC-projekt

Från session 7 kör ni på CSC cPouta, och där hör allt till ett
**projekt**. Ni skaffar ett eget: **ett per par** (solo = ett eget), där
**båda** är medlemmar. Den ena skapar projektet i MyCSC (**Projects → +
New project**), aktiverar molntjänsten (**Services → Pouta → Apply for
Access**) och bjuder in den andra (**Members → Manage invitation link**).

Gör det **den här veckan** — godkännandena går via CSC och kan ta några
dagar. Fullständig steg-för-steg-instruktion: avsnittet **"Efter labben"**
i `labs/m1-forsta-commit.md`.

## Verifiera att allt fungerar

- [ ] Jag kan logga in på GitHub.
- [ ] Jag kan logga in på MyCSC (https://my.csc.fi) med Haka.
- [ ] **Före session 7:** båda i paret ser samma projekt i MyCSC och
      kommer in på https://pouta.csc.fi.

## Vad händer sen?

Resten av dagens M1-lab — skapa ert repo från kursens template, öppna
Codespace eller installera lokalt, och göra första committen — finns i
`labs/m1-forsta-commit.md` (steg 1 och framåt). Ni går igenom det
hands-on tillsammans i klassrummet, så det upprepas inte här.

## Om något strular

Fastna inte ensam — hör av dig till läraren (meddelande till läraren på
itslearning eller e-post) eller ta med problemet olöst till nästa steg i
labben. Vi löser det tillsammans.
